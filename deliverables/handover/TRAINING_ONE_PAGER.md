# SWA ERP — Getting Started (one page)

## Login
Open the internal address in your browser:

> **Login URL:** `PENDING IT ANSWER (Q6)` — the internal hostname IT confirms
> (e.g. `http://erp.swa.local`). Ask your admin / IT for the exact link once
> deployment is done.

Log in with the username and password your **Admin** gave you.

## First steps, by role
- **PM** — Create an Inquiry for a new lead → use *Convert* to make the Client +
  Project → add a Service Agreement and Tokens as work comes in.
- **Designer** — Open your Project → add a Document Reference for each
  report/drawing → log your time.
- **Auditor** — Review compliance checklists and certify Reforge/DPR documents.
- **Admin** — Everything above, plus create user accounts and assign roles (see
  the Administrator Guide).
- **Viewer** — Browse clients, projects, and documents read-only.

## Access problems?
Contact the person who administers the system (your **Admin**). They create
accounts and reset passwords. If the site itself is down, that's an
infrastructure issue for IT — the Admin Guide has the health-check steps.

> Note: this is an internal tool reached over the company VPN. It is not on the
> public internet.
