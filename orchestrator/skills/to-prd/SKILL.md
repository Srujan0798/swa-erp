# to-prd

## Steps
1. Interview user via `agents/interviewer.md` to fill PRD template gaps
2. Sections to ensure:
   - Objective (1 paragraph)
   - User / Problem (who hurts and why)
   - Scope (in / out / out for now)
   - Success metrics (target / acceptable / minimum)
   - Risks (with mitigations)
   - Non-goals (explicit)
3. Write to `plan/PRD.md` (append or revise)
4. If revising existing PRD, move old version to `docs/historical/PRD-vN.md`
